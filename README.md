# AR-подсветка поверхности

Две камеры измеряют высоту над полом, проектор подсвечивает рельеф. Рабочий диапазон — **0–50 см**. Поверхности выше 50 см отображаются чёрным.

Сейчас готовится окончательное крепление. После монтажа нужно заново проверить стереокалибровку, снять пустой пол и откалибровать проектор в 3D. Точное попадание проекции на выступы пока не проверено.

Запуск после настройки — **[start.cmd](start.cmd)**. Остановка — **Esc**. Пока сцена статична, изображение удерживается; при движении обновляется примерно раз в секунду.

В корне оставлены четыре пункта: `start.cmd`, эта инструкция, папка `project/` и архив `history.zip`. Калибровочные данные находятся в `project/stereo_calibration/`. Старые записи проверок и JSON-приёмник перенесены в архив.
