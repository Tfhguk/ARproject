# Запись для воспроизводимого теста

`recorded_wall.npz` содержит 24 исходные карты глубины `depth` (метры, NaN вместо пропусков), выпрямленные серые кадры левой камеры `guide` и программные времена получения `timestamps`.

Сцена — неподвижный стул с коробкой перед деревянной стеной. Настройки камер и хеш калибровки — в `recorded_wall.json`. Запись используется в `tools/check_surface.py` для сравнения одинаковых входных данных. Эталонной глубины для каждого пикселя в ней нет; это тест заполнения и оформления.

`recorded_floor_grid.npz` содержит компактные данные проверки потолочной установки на высоте около 184 см: медианы блоков 8×8 из 41 карты 640×360, метры и NaN, относительные времена `timestamps`, исходный размер карты и хеш калибровки. Это данные до дополнительного сравнения соседних блоков; заполнение для проектора в них не входит. Тесты `test_surface_updates.py` воспроизводят шум записи и добавляют известное изменение глубины на 3 см. Полная запись этого замера сохранена в `results/ceiling_static/raw_sequence.npz`.
