# AR: камеры → высоты → проектор

Команды ниже выполняются из `project/`. Обычный запуск — `start.cmd` в родительской папке.

Текущая задача — подсветка рельефа от пола до 50 см. Высокие объекты получают чёрный цвет. Камеры перевешены 22 ноября; перед рабочей проекцией нужно проверить стереопару и заново снять плоскость пола и привязку проектора.

## Запуск

```powershell
python -m pip install -r requirements.txt
..\start.cmd
```

В запуске включены высоты `--height-map --height-max 0.5`, усиление низких выступов `--height-gamma 0.5`, период обновления около 1 с и сглаживание. Диапазон стереопоиска — 0,5–2,5 м от камер; это отдельная настройка измерения.

Камеры захватывают 1280×720 MJPG, глубина по умолчанию рассчитывается в 640×360. Кнопка **2** включает расчёт 1280×720, но он заметно медленнее. Частота захвата камер отличается от частоты расчёта и проекции.

Текущий прямоугольник проектора — центральные 744×720 пикселей экрана 1280×800 (`--projector-inset-x 268 --projector-inset-y 40`), границы `[268, 40, 1012, 760]`. По прежним замерам полного поля 155×100 см это примерно 90×90 см: предыдущий квадрат 1×1 м уменьшен на 5 см с каждой из четырёх сторон. Физический размер после монтажа проверяется рулеткой.

## Калибровка после монтажа

Если менялись взаимное положение камер или фокус:

```powershell
python -B stereo_calibrate.py --auto --square-mm 24.5 --baseline-mm 131 --focus-left 0 --focus-right 0
```

Покажите доску целиком обеим камерам, меняя положение, высоту и наклон. Автоматически сохраняются 30 устойчивых ракурсов. Физические размеры относятся к прежним подтверждённым измерениям: при новой доске или изменении базы измерьте их заново.

Для начальной границы проектора:

```powershell
..\start.cmd --calibrate-area
```

Выберите в выпрямленном изображении камеры четыре внешних угла белого поля в порядке **1–2–3–4**, затем **Enter**. **Backspace** отменяет точку, **R** очищает выбор, **Esc** отменяет настройку. При этом шаге карта высот и 3D-модель временно не используются.

Новый ноль пола и точное совмещение с выступами:

```powershell
python -B calibrate_projector.py
```

Сначала освободите пол: программа снимает нулевую плоскость и пытается уточнить привязку по четырём проецируемым меткам. Затем накройте две метки белым матовым листом на жёсткой основе, поднимайте его на разные высоты и меняйте наклон. Клавиши **1–5** перемещают пятно. Физическая проверка этого прототипа ещё не завершена; в прошлой позиции не все метки помещались в обзор камер.

Только переснять пол и уточнить плоскую привязку: `python -B calibrate_projector.py --floor-only`. Все метки должны быть видны обеим камерам.

Данные хранятся в `stereo_calibration/`:

| Файл | Назначение |
|---|---|
| `stereo_calibration.npz` | Геометрия стереопары и сохранённый фокус |
| `floor_reference.json` | Измеренная плоскость нулевой высоты |
| `work_area.json` | Связь полного доступного поля проектора с камерой |
| `projector_model.json` | 3D-модель проектора после принятой калибровки |
| `session_*/observations.npz` | Углы доски для повторного расчёта |
| `chessboard.pdf`, `chessboard.svg` | Печатный шаблон доски |

Без принятого `projector_model.json` используется привязка по плоскости пола. Для попадания на выступающие объекты нужна завершённая 3D-калибровка.

## Высоты и обновления

Ноль задаётся плоскостью пола. Рабочий диапазон — **0–0,50 м**; измеренные поверхности выше 0,50 м чёрные. Полоса около нуля 5 мм подавляет мелкий шум. При восстановлении пропусков исключённые объекты не должны окрашиваться; их геометрия остаётся для учёта перекрытия света.

`--height-max` меняет верхний порог, `--height-gamma` — распределение цветов. Значение гаммы меньше 1 усиливает контраст низких выступов. Сглаживание и палитра не повышают точность исходных измерений.

В режиме `changes` глубина проверяется примерно раз в 0,5 с. При движении проекция обновляется не чаще заданного `--update-interval 1`; неподвижная сцена удерживается. Порог изменения в запуске — 10 мм. Время расчёта и подтверждение изменений могут увеличить интервал.

Клавиши в активном окне:

- **R** — собрать новую карту.
- **P** — повторить выбор границы проекции.
- **S** — сила сглаживания, **F** — режим заполнения.
- **1 / 2** — разрешение расчёта.
- **Esc / Q** — закрыть программу и освободить камеры.

Выбор пользовательской зоны через сайт пока описан в [GUI_API.md](docs/GUI_API.md). Это отдельная маска внутри откалиброванного поля; она сохраняет положение изображения.

## Проверки и файлы

```powershell
python -B -m unittest discover -s tests -q
```

Проверяются стереогеометрия, устойчивость к шуму, предел высоты, чёрные перекрывающие объекты, заполнение, сохранение калибровок и вывод с имитацией камер. После монтажа дополнительно нужны физические замеры предметов высотой 5, 10, 25, 50 см и проверка исключения предмета выше порога.

`data/` содержит две небольшие записи для воспроизводимых тестов. `results/` создаётся при новых измерениях. При запуске с `--seconds` сохраняются исходная глубина `*_depth_m.npy`, реальные высоты `*_height_m.npy`, слой для показа и маски. Неизвестные измерения — `NaN`; маска `*_height_active_mask.png` отмечает точки в рабочем диапазоне.

Старые журналы, фотографии калибровок, JSON-приёмник и его замеры помещены в `../history.zip`, раздел `cleanup_20261121_142939/`; содержимое проверено по SHA-256 и CRC. В рабочей папке старые распакованные копии убраны. Активные алгоритмы сглаживания и их записи для тестов сохранены.
